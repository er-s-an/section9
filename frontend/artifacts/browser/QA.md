# Section 9 浏览器 QA

目标：`http://127.0.0.1:5173/`（Vite 前端，API 代理至真实 `127.0.0.1:9019`）。

## 只读范围

本轮只读取首页状态、SSE、运行记录、Playbook、计分屏及可用的运行/RCA详情；没有点击故障注入、reset、自主等级、禁言、审批、暂停/恢复、Attract 或成本专家加入。

## 结果

- 1440×1000：无 console/page error，无 failed request；办公室、代理状态、事件时间线、当前异常、依赖健康均可见。
- 1280×800：无 console/page error，无 failed request；桌面双栏布局保持完整，页面纵向滚动正常。
- 768×800：应用按约定的桌面最小宽度 1040px 保持操作密度，因此出现横向滚动；这不是本项目的移动目标，但不应在移动设备上误判为响应式布局。
- 三个尺寸均确认四个页签存在：办公室、运行记录、Playbook、五行计分。
- Tab 键顺序进入刷新、导航、重置和故障按钮，未发现焦点陷入不可见区域。
- 当前真实服务返回五行计分但运行记录为空，故本轮无法打开真实 run/RCA 详情；没有伪造运行记录。
- 页面显示真实后端代理集合（哨兵、诊断员、修复者 A/B、复核员、单 Agent 基线），静态像素工位只承载这些 snapshot 角色，不生成状态。
