## 验证边界

本轮仅修改前端、展示原型与浏览器脚本的定位，未改动后端执行权限、模型调用或数据库合同，也未追加收费推理。旧模型闭环证据不能作为新 UI 的浏览器验证，二者分别保存。

- `npm --prefix frontend run build`：TypeScript 与 Vite 构建。
- `node scripts/browser-product-preview.mjs`：预览六步骤、专家显隐、弹层键盘操作、暂停恢复、1440/1280/390 布局。合成预览检查。
- `node scripts/browser-product-copy.mjs`：真实服务只读检查。主界面、记录、经验、待测评分、双侧对照、历史失败、证据入口及原始记录折叠。禁止写请求和推理调用。
- `node scripts/browser-product-scope.mjs`：组件级接口替身；作用域文案、失败展示、轮询与素材成功/失败路径。不是模型闭环证明。

证据：`artifacts/product-ux/20260922/`，含前后截图、可见文字与 JSON 验证报告。

本轮不宣称完成新的复杂任务基准、稳定性验收或离线推理验证。部署在本机，未自动提交或上传 GitHub。
