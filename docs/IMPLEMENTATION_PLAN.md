## EvoMap 接入分层

本地 swarm 的开发和运行不以社区 Hub 声望为前提。此前将社区接口的声望条件前置到本地闭环的规划已撤回。

1. **本地协作与安全执行**：四角色各自循环、自主认领、受限工具、租约与 fencing、独立验收。共享状态服务只维护确定性状态，不代替 agent 做诊断或分派专家。
2. **官方 GEP 格式与本地能力复用**：当前 `@evomap/gep-sdk` 提供 schema、协议及 asset-id 等工具；不把它描述成完整的 swarm 调度 SDK。`@evomap/gep-mcp-server` 明确提供默认 local mode，通过 `GEP_ASSETS_DIR` / `GEP_MEMORY_DIR` 读写本地资产和记忆，可作为记忆层优先复用候选。Evolver 的具体传输与资产能力按源码和固定版本验证后选用。上述包目前只读核查，尚未安装或运行。
3. **远程经验网络**：开发者 OAuth API、节点 A2A API 与模型 API 是不同鉴权面。模型密钥已验证，不代表已有开发者 OAuth token 或节点身份。所需网络操作单独验证，不阻塞本地首次修复。

公开开发者 quickstart 展示了 OAuth PKCE、gene/recipe/reuse 的读取及 recipe 发布接入；不能据此宣称已获得原 PRD 全部 A2A 会话、Capsule 发布或 Runtime Hooks 能力。原生能力与项目本地实现分别记录，缺失项不标完成。

## 实现顺序与验收

### 第一批：最小契约与可运行病人

- 主 agent 冻结第一条闭环需要的事件、配置版本、有限修复动作、动作回执和验收结果契约；后续契约按版本增补。
- 导入小智内容资产，建立真实 `/chat` 与政策 / 产品查询工具；健康与坏 prompt 都走同一真实模型路径。
- 模型适配器验证非空响应、结构化输出、工具调用、deadline 和真实 usage；空答案或超时明确失败。
- 先做一类 prompt 故障：注入真实配置变更，修复通过受控入口切换配置，独立请求确认恢复。
- 启动一套开发栈，接 Langfuse 证据路径和 Collector 控制路径，测实际延迟与内存。后台观测故障不得拖住控制闭环。

通过条件：从正常到故障再恢复可重复；修复者不能调用注入器；业务行为和配置版本均真实变化，原始记录可查。

### 第二批：四角色闭环与安全边界

- 哨兵用阈值、探针、进度与心跳；其他角色自主认领并交换结构化证据。
- 主 agent 负责执行事务：权限、租约、epoch、资源 fence、配置 CAS、幂等性、动作回执和审计一致提交。
- 修复和 reset 要取消受影响的在途请求；工具调用边界检查取消状态。
- 外部验收后按 tested revision 与验收合同进行 CAS 结案，避免测试后配置变化仍显示成功。
- 真实暂停 fixer-A，让 fixer-B 接管，恢复 A 后旧请求被拒且配置不变。

### 第三批：故障覆盖与可见协作

- 补成本膨胀、工具死循环、复合故障；复合故障只修一半不能通过。
- 接真实事件驱动的办公室、控制面板、RCA 和 Playbook 列表；执行动作和验收成功分别呈现。
- 本地经验命中仍经过新授权和独立验收；远端发布状态单独显示。
- 新成本专家经能力发现和自主认领接入；通信开关作用于真实消息层。

### 第四批：实验与交付

- 公平基线使用同等模型、底层事实、工具和总预算；无记忆与有记忆条件分开。
- 记录失败、超时、缓存、推理 usage 与传输模式，展示未测格；通信测试结果不预设退化结论。
- 开发阶段一套栈先运行。demo / attract / eval 的数据、缓存、身份与消息分别隔离；同机分时运行不标为硬件物理隔离完成。
- 做 reset、断 EvoMap、办公室故障和其他已实现依赖的降级彩排，完成备份录像及材料。

## 低成本 subagent 任务边界

| 执行任务 | 允许范围 | 交付验收 |
| --- | --- | --- |
| victim 和 probe | victim、导入资产、检测与验收样例 | 真模型可调用；坏版本检出；健康版本恢复；检测/验收分开 |
| infra 和遥测 | Compose、Collector、健康检查及适配器 | 控制/证据路径分别可查；故障不互相阻塞；版本固定 |
| 展示和实验读取 | office bridge、控制面板、RunRecord 查询 | 全部状态有真实事件来源；未测结果不产生分数 |

主 agent 独占公共 schema、依赖锁和 migration 的合入入口，负责跨模块集成及独立验收。每次任务包含允许修改文件、契约版本、样例和验收命令；出现跨模块设计问题或连续返工时收回处理。
